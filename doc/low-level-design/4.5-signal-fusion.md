# 4.5 Signal Fusion

## Overview

The signal fusion module combines perception outputs from multiple modalities (face, body, audio, gaze) into unified social cue signals. It uses reliability-weighted fusion to handle missing or low-confidence inputs gracefully, ensuring robust cue generation even when individual modalities are degraded.

## Fusion Strategies

### Reliability-Weighted Average

The default fusion strategy weights each modality by its confidence score:

```
fused_signal = Σ(modality_signal × modality_confidence) / Σ(modality_confidence)
```

| Property | Description |
|----------|-------------|
| Method | Weighted arithmetic mean |
| Weight source | Per-modality confidence scores |
| Missing handling | Zero weight for absent modalities |
| Normalization | Output scaled to [0, 1] |

---

### Cross-Modal Validation

Signals that appear in multiple modalities receive boosted confidence:

| Signal | Face | Body | Audio | Validation Boost |
|--------|------|------|-------|------------------|
| Engagement | ✅ Eye contact | ✅ Lean forward | ✅ Response timing | +20% confidence |
| Discomfort | ✅ Frown | ✅ Crossed arms | ❌ — | +10% confidence |
| Agreement | ✅ Head nod | ❌ — | ✅ Vocal affirmation | +15% confidence |

### Confidence Thresholds

| Condition | Threshold | Action |
|-----------|-----------|--------|
| Modality confidence | < 0.3 | Exclude from fusion |
| Fused signal confidence | < 0.4 | Mark as uncertain |
| No modalities available | — | Output null cue |
| Single modality only | — | Reduce output confidence by 30% |

## Latency Budget

| Stage | Target | Maximum |
|-------|--------|---------|
| Signal mapping | 1ms | 2ms |
| Weight computation | 0.5ms | 1ms |
| Signal combination | 2ms | 3ms |
| Normalization | 0.5ms | 1ms |
| **Total** | **5ms** | **10ms** |

## Sequence Diagram

```mermaid
sequenceDiagram
    participant Perception as PerceptionPipeline
    participant Pipeline as SignalFusionPipeline
    participant Mapper as SignalMapper
    participant Weighter as ReliabilityWeighter
    participant Combiner as SignalCombiner
    participant Norm as OutputNormalizer
    participant Temporal as TemporalAggregation

    Note over Perception,Temporal: Fusion Processing Flow

    Perception->>Pipeline: PerceptionResult

    loop For Each Cue Type
        Pipeline->>Mapper: mapToCue(cueType, perception)
        Mapper->>Mapper: extractSignal(FACE)
        Mapper->>Mapper: extractSignal(BODY)
        Mapper->>Mapper: extractSignal(AUDIO)
        Mapper->>Mapper: extractSignal(GAZE)
        Mapper-->>Pipeline: MappedSignals

        Pipeline->>Weighter: computeWeights(cueType, signals)
        Weighter->>Weighter: checkConfidenceThresholds()
        Weighter->>Weighter: applyConfidenceScaling()

        alt Cross-Modal Validation
            Weighter->>Weighter: detectCrossModalValidation()
            Weighter->>Weighter: applyValidationBoost()
        end
        Weighter-->>Pipeline: WeightedSignals

        Pipeline->>Combiner: combine(weighted)

        alt Missing Modalities
            Combiner->>Combiner: handleMissingModalities()
            Combiner->>Combiner: rebalanceWeights()
        end

        Combiner->>Combiner: applyFusionStrategy()
        Combiner-->>Pipeline: fusedValue

        Pipeline->>Norm: normalize(fusedValue)
        Norm->>Norm: clampToRange()
        Norm->>Norm: computeOutputConfidence()
        Norm-->>Pipeline: FusedCueSignal
    end

    Pipeline->>Pipeline: aggregateCueSignals()
    Pipeline-->>Temporal: FusedCueSignals
```
