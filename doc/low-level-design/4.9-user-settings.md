# 4.9 User Settings

## Overview

The user settings module manages persistent user preferences and runtime controls for the SecondSight application. It provides a unified interface for storing, retrieving, and applying settings across all pipeline components while respecting platform-specific storage mechanisms.

## Setting Categories

### Feedback Settings

| Setting | Type | Default | Range | Description |
|---------|------|---------|-------|-------------|
| Visual feedback enabled | bool | true | — | Enable visual cue display |
| Audio feedback enabled | bool | false | — | Enable audio cues |
| Haptic feedback enabled | bool | true | — | Enable haptic feedback |
| Global intensity | float | 0.7 | [0.0, 1.0] | Overall feedback strength |
| Reduce motion | bool | false | — | Minimize animations |

### Privacy Settings

| Setting | Type | Default | Range | Description |
|---------|------|---------|-------|-------------|
| Recording allowed | bool | false | — | Allow session recording |
| Research mode consent | bool | false | — | Opt-in for research data |
| Bystander auto-pause | bool | true | — | Pause when others nearby |
| Privacy indicator visible | bool | true | — | Show recording indicator |

### Processing Settings

| Setting | Type | Default | Range | Description |
|---------|------|---------|-------|-------------|
| Quality level | enum | BALANCED | LOW/BALANCED/HIGH | Processing quality |
| Target FPS | int | 30 | [10, 60] | Target frame rate |
| Face analysis enabled | bool | true | — | Enable face processing |
| Body analysis enabled | bool | true | — | Enable body processing |
| Audio analysis enabled | bool | true | — | Enable audio processing |

### Accessibility Settings

| Setting | Type | Default | Range | Description |
|---------|------|---------|-------|-------------|
| High contrast mode | bool | false | — | Increase visual contrast |
| Large text | bool | false | — | Increase text size |
| Screen reader support | bool | false | — | Enable screen reader hints |
| Color blind mode | enum | NONE | NONE/PROTANOPIA/DEUTERANOPIA | Color adjustment |

## Class Diagram

```mermaid
classDiagram
    class ISettingsStorage {
        <<interface>>
        +load(key: string) any
        +save(key: string, value: any) void
        +delete(key: string) void
        +exists(key: string) bool
        +getAll() Map~string, any~
    }

    class SettingsManager {
        -storage: ISettingsStorage
        -schema: SettingsSchema
        -observers: Map~string, SettingObserver[]~
        -cache: Map~string, any~
        +get(key: string) any
        +set(key: string, value: any) void
        +reset(key: string) void
        +resetAll() void
        +observe(key: string, observer: SettingObserver) void
        +unobserve(key: string, observer: SettingObserver) void
    }

    class SettingsSchema {
        -definitions: Map~string, SettingDefinition~
        +validate(key: string, value: any) ValidationResult
        +getDefault(key: string) any
        +getType(key: string) SettingType
        +getRange(key: string) Range?
        +getAllDefinitions() SettingDefinition[]
    }

    class VersionMigrator {
        -migrations: Map~int, Migration~
        -currentVersion: int
        +migrate(settings: Map~string, any~, fromVersion: int) Map~string, any~
        +needsMigration(version: int) bool
        +getCurrentVersion() int
    }

    class ChangeObserver {
        -listeners: Map~string, Callback[]~
        +notify(key: string, oldValue: any, newValue: any) void
        +subscribe(key: string, callback: Callback) void
        +unsubscribe(key: string, callback: Callback) void
        +notifyBatch(changes: SettingChange[]) void
    }

    class QuickControls {
        -settingsManager: SettingsManager
        -currentState: QuickControlState
        +toggle(control: QuickControlType) void
        +getState(control: QuickControlType) bool
        +emergencyDisable() void
        +getAvailableControls() QuickControlType[]
    }

    class LocalStorage {
        -preferencesHandle: PreferencesHandle
        +load(key: string) any
        +save(key: string, value: any) void
        +delete(key: string) void
    }

    class CloudSyncStorage {
        -localStorage: LocalStorage
        -syncService: SyncService
        +load(key: string) any
        +save(key: string, value: any) void
        +sync() void
        +resolveConflict(local: any, remote: any) any
    }

    ISettingsStorage <|.. LocalStorage
    ISettingsStorage <|.. CloudSyncStorage

    SettingsManager *-- ISettingsStorage
    SettingsManager *-- SettingsSchema
    SettingsManager *-- VersionMigrator
    SettingsManager *-- ChangeObserver
    QuickControls --> SettingsManager : uses
    CloudSyncStorage --> LocalStorage : wraps
```

## Sequence Diagram

```mermaid
sequenceDiagram
    participant UI as Settings UI
    participant Quick as QuickControls
    participant Manager as SettingsManager
    participant Schema as SettingsSchema
    participant Storage as ISettingsStorage
    participant Observer as ChangeObserver
    participant Consumer as Pipeline/Feedback

    Note over UI,Consumer: Setting Change Flow

    alt From Settings UI
        UI->>Manager: set("feedback.intensity", 0.8)
    else From Quick Controls
        Quick->>Manager: toggle("enabled")
    end

    Manager->>Schema: validate("feedback.intensity", 0.8)
    Schema->>Schema: checkType()
    Schema->>Schema: checkRange()

    alt Validation Failed
        Schema-->>Manager: INVALID, error
        Manager-->>UI: ValidationError
    else Validation Passed
        Schema-->>Manager: VALID

        Manager->>Manager: getOldValue()
        Manager->>Storage: save("feedback.intensity", 0.8)
        Storage-->>Manager: success

        Manager->>Manager: updateCache()
        Manager->>Observer: notify("feedback.intensity", 0.7, 0.8)

        Observer->>Consumer: onSettingChanged("feedback.intensity", 0.8)
        Consumer->>Consumer: applyNewSetting()

        Manager-->>UI: success
    end

    Note over UI,Consumer: Settings Load Flow (App Start)

    Manager->>Storage: getAll()
    Storage-->>Manager: savedSettings

    Manager->>Schema: validateAll(savedSettings)

    alt Migration Needed
        Manager->>Manager: migrate(savedSettings, oldVersion)
    end

    Manager->>Manager: populateCache()
    Manager->>Observer: notifyBatch(allSettings)
    Observer->>Consumer: onSettingsLoaded(allSettings)
```
