# 4.11 Raw Data Storage

## Overview

The raw data storage module manages session recording, data persistence, and export functionality for Training and Research modes. It ensures data integrity, enforces retention policies, and provides secure export mechanisms while respecting user privacy preferences.

## Recording Capabilities

### By Operating Mode

| Capability | Assistive | Training | Research |
|------------|-----------|----------|----------|
| Session recording | ❌ Disabled | ✅ Enabled | ✅ Enabled |
| Frame storage | ❌ | ⚪ Optional | ✅ Full |
| Cue logging | ❌ | ✅ Summary | ✅ Full |
| Metadata capture | ❌ | ✅ Session | ✅ Detailed |
| Export available | ❌ | ✅ Local | ✅ Full |

### Data Types Recorded

| Data Type | Training | Research | Format |
|-----------|----------|----------|--------|
| Processed frames | Optional | Yes | Compressed video |
| Raw sensor data | No | Optional | Binary |
| Feature vectors | Yes | Yes | Binary arrays |
| Cue signals | Yes | Yes | JSON/Binary |
| Session metadata | Yes | Yes | JSON |
| User annotations | Yes | Yes | JSON |

## Retention Policies

| Mode | Default Retention | User Override | Auto-Delete |
|------|-------------------|---------------|-------------|
| Training | 7 days | 1-30 days | On mode exit option |
| Research | 90 days | Study-defined | Never (manual only) |

## Class Diagram

```mermaid
classDiagram
    class IDataStorage {
        <<interface>>
        +write(data: bytes, path: string) void
        +read(path: string) bytes
        +delete(path: string) void
        +exists(path: string) bool
        +getSize(path: string) int
    }

    class DataRecorder {
        -storage: IDataStorage
        -buffer: WriteBuffer
        -encoder: DataEncoder
        -currentSession: RecordingSession
        +startSession(config: RecordingConfig) RecordingSession
        +stopSession() SessionSummary
        +recordFrame(frame: ProcessedFrame) void
        +recordCue(cue: SafeCue) void
        +pauseRecording() void
        +resumeRecording() void
    }

    class RecordingSession {
        -sessionId: string
        -startTimestamp: int64
        -config: RecordingConfig
        -frameCount: int
        -cueCount: int
        +getSessionId() string
        +getDuration() int
        +getFrameCount() int
        +getCueCount() int
        +getMetadata() SessionMetadata
    }

    class WriteBuffer {
        -bufferSize: int
        -flushThreshold: int
        -pendingData: bytes[]
        +add(data: bytes) void
        +flush() void
        +clear() void
        +getPendingSize() int
    }

    class DataEncoder {
        -compressionLevel: int
        -format: EncodingFormat
        +encodeFrame(frame: ProcessedFrame) bytes
        +encodeCue(cue: SafeCue) bytes
        +encodeMetadata(meta: SessionMetadata) bytes
        +decode(data: bytes, type: DataType) any
    }

    class SessionExporter {
        -storage: IDataStorage
        +export(sessionId: string, format: ExportFormat) ExportResult
        +exportAnonymized(sessionId: string) ExportResult
        +getExportSize(sessionId: string, format: ExportFormat) int
        +cancelExport(exportId: string) void
    }

    class RetentionManager {
        -storage: IDataStorage
        -policies: Map~OperatingMode, RetentionPolicy~
        +checkRetention() void
        +deleteExpired() int
        +setPolicy(mode: OperatingMode, policy: RetentionPolicy) void
        +getSessionsForDeletion() RecordingSession[]
    }

    class LocalStorage {
        -basePath: string
        +write(data: bytes, path: string) void
        +read(path: string) bytes
        +delete(path: string) void
        +listSessions() string[]
    }

    IDataStorage <|.. LocalStorage

    DataRecorder *-- WriteBuffer
    DataRecorder *-- DataEncoder
    DataRecorder --> IDataStorage : uses
    DataRecorder --> RecordingSession : creates

    SessionExporter --> IDataStorage : uses
    RetentionManager --> IDataStorage : uses
```

## Sequence Diagram

```mermaid
sequenceDiagram
    participant Mode as TrainingModeHandler
    participant Recorder as DataRecorder
    participant Buffer as WriteBuffer
    participant Encoder as DataEncoder
    participant Storage as IDataStorage
    participant Retention as RetentionManager

    Note over Mode,Retention: Recording Session Flow

    Mode->>Recorder: startSession(config)
    Recorder->>Recorder: createSessionId()
    Recorder->>Storage: createSessionDirectory(sessionId)
    Recorder-->>Mode: RecordingSession

    loop Frame Recording
        Mode->>Recorder: recordFrame(frame)
        Recorder->>Encoder: encodeFrame(frame)
        Encoder-->>Recorder: encodedData
        Recorder->>Buffer: add(encodedData)

        alt Buffer Full
            Buffer->>Storage: write(bufferedData, path)
            Buffer->>Buffer: clear()
        end
    end

    loop Cue Recording
        Mode->>Recorder: recordCue(cue)
        Recorder->>Encoder: encodeCue(cue)
        Encoder-->>Recorder: encodedCue
        Recorder->>Recorder: appendToCueBuffer()
    end

    Mode->>Recorder: stopSession()
    Recorder->>Buffer: flush()
    Buffer->>Storage: write(remainingData, path)
    Recorder->>Recorder: generateMetadata()
    Recorder->>Storage: write(metadata, metaPath)
    Recorder-->>Mode: SessionSummary

    Note over Mode,Retention: Retention Check

    Retention->>Retention: checkRetention()
    Retention->>Storage: listSessions()
    Storage-->>Retention: sessions[]

    loop For Each Session
        Retention->>Retention: isExpired(session)
        alt Expired
            Retention->>Storage: delete(sessionPath)
        end
    end
```
