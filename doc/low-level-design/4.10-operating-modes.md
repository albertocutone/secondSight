# 4.10 Operating Modes

## Overview

The operating modes module manages the three distinct operational states of SecondSight: Assistive (default), Training, and Research modes. Each mode has different behaviors regarding cue output, data recording, and privacy constraints.

## Mode Definitions

### Assistive Mode (Default)

| Property | Value | Description |
|----------|-------|-------------|
| Purpose | Real-time assistance | Live social cue support |
| Cue output | Safe cues only | Observable descriptions |
| Recording | Disabled | No data persisted |
| Feedback | Subtle | Non-intrusive presentation |
| Consent required | Basic | Face/voice analysis |

### Training Mode

| Property | Value | Description |
|----------|-------|-------------|
| Purpose | Practice sessions | Learn to recognize cues |
| Cue output | Safe cues + labels | Educational annotations |
| Recording | Session only | Auto-delete after review |
| Feedback | Enhanced | Replay with explanations |
| Consent required | Extended | Recording consent |

### Research Mode

| Property | Value | Description |
|----------|-------|-------------|
| Purpose | Data collection | IRB-approved studies |
| Cue output | Full signals | Research-grade data |
| Recording | Persistent | Long-term storage |
| Feedback | Configurable | Study-specific |
| Consent required | Full | Research consent |

## Mode Transitions

### Valid Transitions

| From | To | Requirements |
|------|-----|--------------|
| Assistive | Training | Recording consent |
| Assistive | Research | Full research consent |
| Training | Assistive | None |
| Training | Research | Full research consent |
| Research | Assistive | None |
| Research | Training | None |

### Transition State Machine

```mermaid
stateDiagram-v2
    [*] --> Assistive

    Assistive --> Training: recordingConsent
    Assistive --> Research: researchConsent

    Training --> Assistive: userRequest
    Training --> Research: researchConsent

    Research --> Assistive: userRequest
    Research --> Training: userRequest

    Assistive --> [*]: shutdown
    Training --> [*]: shutdown
    Research --> [*]: shutdown
```

## Consent Requirements by Mode

| Consent Type | Assistive | Training | Research |
|--------------|-----------|----------|----------|
| Face analysis | ✅ Required | ✅ Required | ✅ Required |
| Voice analysis | ✅ Required | ✅ Required | ✅ Required |
| Data recording | ❌ N/A | ✅ Required | ✅ Required |
| Research sharing | ❌ N/A | ❌ N/A | ✅ Required |
| Training contribution | ❌ N/A | ⚪ Optional | ⚪ Optional |

## Sequence Diagram

```mermaid
sequenceDiagram
    participant UI as Mode UI
    participant Manager as ModeManager
    participant Validator as TransitionValidator
    participant Consent as ConsentManager
    participant OldMode as CurrentModeHandler
    participant NewMode as TargetModeHandler
    participant Pipeline as ProcessingPipeline

    Note over UI,Pipeline: Mode Switch Flow

    UI->>Manager: switchMode(TRAINING)
    Manager->>Manager: getCurrentMode() -> ASSISTIVE

    Manager->>Validator: validate(ASSISTIVE, TRAINING)
    Validator->>Validator: getRequiredConsents(TRAINING)
    Validator->>Consent: checkConsentStatus([RECORDING])

    alt Consent Missing
        Consent-->>Validator: MISSING
        Validator-->>Manager: INVALID, missingConsents
        Manager-->>UI: ConsentRequired([RECORDING])

        UI->>Consent: requestConsent([RECORDING])
        Consent-->>UI: GRANTED
        UI->>Manager: switchMode(TRAINING)
    end

    Consent-->>Validator: GRANTED
    Validator-->>Manager: VALID

    Manager->>OldMode: onExit(context)
    OldMode->>OldMode: cleanup()
    OldMode-->>Manager: done

    Manager->>NewMode: onEnter(context)
    NewMode->>NewMode: initializeRecording()
    NewMode->>NewMode: configurePolicy()
    NewMode-->>Manager: ModeConfiguration

    Manager->>Pipeline: applyConfiguration(config)
    Pipeline->>Pipeline: updatePolicyGate()
    Pipeline->>Pipeline: updateFeedback()
    Pipeline-->>Manager: applied

    Manager->>Manager: setCurrentMode(TRAINING)
    Manager-->>UI: TransitionResult(SUCCESS)
```
